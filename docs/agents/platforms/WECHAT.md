# WeChat Mini Program Rules

## 适用场景

- 修改微信小程序页面、组件、配置、权限、网络或平台 API

## 必须

- 遵循项目现有基础库版本、分包策略和构建方式
- 页面状态通过明确的 `setData` 或项目封装更新，避免传输无关大对象
- 平台 API 的成功、失败、取消和权限拒绝路径必须被处理
- 路由、生命周期和页面卸载后的异步回调不得继续修改失效状态

## 建议

- 优先使用原生组件和项目已有跨页面能力
- 控制首包、图片和请求体积，避免无依据的预加载
- 将平台权限和兼容性判断集中在清晰边界内

## 避免

- 在 WXML 中放置复杂表达式或隐式业务逻辑
- 频繁、大范围 `setData`
- 假设开发者工具行为与真机完全一致

## 验证

- 使用项目既有命令检查类型和构建，并在开发者工具或真机检查生命周期及权限路径
