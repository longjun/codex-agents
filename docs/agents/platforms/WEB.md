# Web Platform Rules

## 适用场景

- 修改浏览器页面、Web API、样式、交互或客户端运行行为

## 必须

- 使用语义化 HTML，并保持键盘、焦点和表单行为可用
- 不信任客户端输入；前端校验不替代服务端校验
- 浏览器 API 使用符合项目支持范围，必要时提供降级路径
- 响应式布局不依赖单一固定视口

## 建议

- 优先使用原生浏览器能力和渐进增强
- 保持内容、样式、交互和数据流边界清晰
- 避免不必要的 JavaScript、资源和渲染阻塞

## 避免

- 用 `div` 模拟已有原生控件
- 无必要阻止默认行为、破坏返回键或深链接
- 依赖 hover、精确指针或特定区域设置作为唯一交互方式

## 验证

- 检查主要视口、键盘操作、加载失败和至少一个真实浏览器环境
