# macOS Rules

## 适用场景

- 修改以 macOS 为目标的平台能力、应用生命周期、权限或系统集成

## 必须

- 遵循项目最低系统版本、sandbox、entitlement 和签名配置
- 权限申请必须有对应使用说明，并在拒绝或受限时提供可恢复路径
- 文件、进程、窗口和系统服务调用符合 macOS 生命周期及安全边界
- 不假设开发机权限、路径或安装状态在用户环境中存在

## 建议

- 优先使用系统 API、标准交互和用户可预期的位置
- 持久化用户选择时优先保存安全、可恢复的引用，而不是脆弱绝对路径
- 对系统版本差异使用清晰的 availability 分支

## 避免

- 无必要扩大 entitlement 或关闭 sandbox
- 阻塞主线程执行系统调用、文件 I/O 或进程等待
- 硬编码用户目录、应用路径或区域设置

## 验证

- 在最低支持版本边界检查构建、权限拒绝、重启和多窗口行为
