# Accessibility Rules

## 适用场景

- 修改用户可操作界面、导航、表单、反馈或内容呈现

## 必须

- 使用平台原生语义和控件；自定义控件必须提供等价名称、角色、状态和操作
- 所有操作可通过键盘或平台辅助输入完成，焦点顺序清晰且可见
- 表单具有可关联标签，错误说明具体且不只依赖颜色
- 内容适应文本放大、动态字体和常见窗口或视口变化
- 动画、自动播放和时间限制尊重平台辅助功能设置

## 建议

- 优先修复语义和交互结构，而不是附加补丁式 ARIA 或辅助标签
- 加载、空、错误和成功反馈可被辅助技术感知
- 颜色、图标和文案共同表达重要状态

## 避免

- 用 placeholder 代替持久标签
- 只有 hover、手势或颜色才能发现的操作
- 无必要移动焦点、捕获键盘或覆盖系统导航行为

## 验证

- 使用键盘完成关键流程，并使用目标平台辅助技术检查名称、状态和焦点
