# Agent Rule Modules

本目录存放由根 `AGENTS.md` 按任务实际修改面加载的技术规则。

## 维护原则

- 每条规则只放在最具体的一个模块中，避免跨文件重复
- 规则描述可执行约束，不写成技术教程
- 使用“适用场景、必须、建议、避免、验证”组织内容
- 只添加已被真实任务验证的规则，不创建空占位文件
- 框架、语言、平台、领域和工具相互独立，由根路由协议组合
- 修改规则后，至少用一个适用任务和一个不适用任务检查路由边界

## 模块职责

- `languages/`：语言语义、标准库和生态惯例
- `frameworks/`：框架生命周期、组件边界和框架约定
- `platforms/`：目标运行环境、系统能力和平台限制
- `domains/`：跨语言的业务或系统边界
- `tooling/`：测试、构建、容器和 CI 工具

通用工程原则和路由索引保留在根 `AGENTS.md`，本目录不重复维护。
