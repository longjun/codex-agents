# AppKit Rules

## 适用场景

- 修改 AppKit 窗口、控制器、视图、菜单或应用生命周期

## 必须

- UI 更新在主线程执行
- 明确 delegate、notification、timer 和 observer 的所有权及释放路径
- 遵循 responder chain 和系统生命周期，不用全局状态绕过正常事件流
- Auto Layout 约束必须完整且无歧义

## 建议

- 优先使用 AppKit 原生控件和行为
- controller 负责界面协调，将可独立验证的业务逻辑移出表现层
- 与 SwiftUI 混用时保持清晰的状态所有权和桥接边界

## 避免

- 在绘制或高频事件中执行阻塞 I/O
- 无必要重写系统控件行为
- 长生命周期闭包对控制器或视图形成强引用环

## 验证

- 检查窗口生命周期、菜单、键盘操作、焦点和不同窗口状态
